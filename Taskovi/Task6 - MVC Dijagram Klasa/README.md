# MVC dijagram klasa

Potrebno je u dijagram klasa dodati kontrolerske klase i klase pogleda. Klase pogleda trebaju biti prazne, a kontrolerske klase trebaju sadržavati sve rute neophodne za rad sistema. Potrebno je prikazati i DataContext klasu i njene atribute.

## Kreiranje modela i migracija na bazu podataka

Potrebno je implementirati model kreiranog dijagrama klasa koji poštuje SOLID principe i izvršiti migraciju modela na bazu podataka po uputama iz laboratorijske vježbe.
