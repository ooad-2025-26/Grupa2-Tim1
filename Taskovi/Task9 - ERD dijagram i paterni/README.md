# Deveti projektni zadatak

## Kreacijski paterni

Potrebno je kreirati dokument u kojem se objašnjava potreba za dodavanjem kreacijskih paterna u postojeći sistem. Kreirati i novi klasni dijagram (na osnovu prvog klasnog dijagrama) na kojim će se dodati dva odabrana kreacijska paterna. 

Ovakav dijagram klasa nije potrebno implementirati. Za implementaciju se koristi MVC dijagram

## ERD (entity relationship dijagram)

Potrebno je dizajnirati i detaljno razraditi ERD sistema koristeći dijagram klasa za model sistema i neophodne korake za prilagođavanje klasa tabelama baze podataka, prema uputstvima iz laboratorijske vježbe 6.
